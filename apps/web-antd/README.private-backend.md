# 通过 SSH 隧道联调服务器后端

适用于备案期间的后台预发布联调；不需要开放服务器的 `8888` 公网端口，也不要把 Vite 开发服务器部署到公网。现有服务器和数据库是预发布环境，Spring `prod` profile 仍用于安全配置，不表示测试数据会转为正式账本。

1. 在本机终端建立 SSH 隧道并保持窗口打开：

   ```powershell
   ssh -N -L 127.0.0.1:18888:127.0.0.1:8888 ubuntu@服务器公网IP
   ```

2. 确认本机访问 `http://127.0.0.1:18888/actuator/health` 返回 `{"status":"UP"}`。不要把管理员令牌或密码贴进命令行参数、截图或日志。
3. 在 `apps/web-antd` 中新建未跟踪的 `.env.development.local`，填写：

   ```dotenv
   DEV_API_PROXY_TARGET=http://127.0.0.1:18888
   VITE_APP_TITLE=积分平台管理后台（预发布）
   ```

4. 在管理后台仓库根目录重新启动开发服务：

   ```powershell
   pnpm dev:antd
   ```

   浏览器只在本机访问 `http://127.0.0.1:5666`，用服务器管理员的新密码登录。先确认仪表盘、门店列表等只读页面可打开。MySQL 备份和预发布测试数据方案准备好后，可以在这套预发布库验证充值、消费、退款和结算；不能做真实收款，也不能把这些测试流水带入正式账本。

使用自定义代理目标时，Vite 仅监听 `127.0.0.1`；该目标也只允许指向本机 HTTP 端口。它由 Vite 服务端读取，不会作为 `VITE_` 前缀配置发送给浏览器。不配置 `DEV_API_PROXY_TARGET` 时，默认仍连接本机 `http://localhost:8888`，现有开发方式不变。联调结束后删除本地 `.env.development.local` 并重新启动开发服务，以免下次误连服务器。

不要把仓库中的 `dev/sql/seed-local-demo-data.sql` 导入服务器，它含有公开演示密码且明确只供本地开发。服务器开始任何预发布资金流程测试前，先使用 1Panel 为 MySQL 建立定期备份，并把备份副本保存到服务器之外；Redis 持久化不等于备份。正式上线时另建干净数据库及独立 Redis 数据空间，不直接将此库转正。
